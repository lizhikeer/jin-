# 浙江金华科贸职业技术学院 - 自动抢课工具

本仓库提供适配**浙江金华科贸职业技术学院**正方教务系统（`https://jwxt.zjjhkm.edu.cn/jwglxt`）的自动选课工具，包含两个版本：

1. 🚀 **Go 极速多账号面板版（推荐）**：位于 `go-panel/`，单文件运行，支持多账号并发、Web 页面可视化管理、会话自动保活与双保险重登、课程表优先级调度、DryRun 干跑模式与实时日志；
2. 🐍 **Python 单账号脚本版**：位于 `qiangke_zjjhkm/`，轻量命令行脚本，支持基础的余量轮询与定时选课。

---

## 🚀 方式一：Go 极速多账号面板版（推荐）

### 特性
- 💻 **免装环境**：Windows 预编译单文件可执行程序，双击批处理即开即用；
- 👥 **多账号并发**：支持多账号同时挂机抢课，各自独立会话与课程表；
- 🔐 **双重保险**：Cookie 自动持久化与复用，失效时自动使用正方账密（RSA PKCS#1 v1.5）重新登录；
- 🛡️ **安全干跑**：内置 DryRun 模式，可预先演练全流程而不真实提交选课；
- 📊 **Web 控制台**：内嵌单页面板（默认端口 `18080`），包含实时倒计时、轮询间隔、SMTP 邮件提醒与实时运行日志。

### 快速开始

1. **一键启动**：
   - 直接双击仓库根目录下的 **`启动面板.bat`**（或进入 `go-panel/` 双击 `启动面板.bat`）；
   - 浏览器将自动打开管理面板：`http://127.0.0.1:18080`。

2. **添加账号与验证**：
   - 点击面板上方 **【＋ 添加账号】**；
   - 输入备注名、正方教务学号与登录密码，保存；
   - 在账号列表点击 **【🧪 登录】** 进行登录验证，测试通过后将显示绿色会话正常状态并缓存 Cookie。

3. **配置课程表**：
   - 点击账号右侧 **【✏ 编辑】**；
   - 在下方课程表中填入教学班名称（格式如 `(2026-2027-1)-课程号-班号`），选择动作（选课 / 退课）；
   - 支持按顺序调整优先级；如选课已开放可点击 **【🔄 更新课程库】** 从教务系统直接拉取全校教学班信息并支持下拉补全。

4. **运行抢课**：
   - 在顶部全局设置中配置运行模式：
     - **定时抢课**：适合整点选课，设置好开始时间后程序将自动提前刷新会话并到点毫秒级开抢；
     - **蹲课捡漏**：适合选课开放后轮询余量，发现空位立即选入；
   - 建议首次使用时勾选 **【开启干跑模式 (DryRun)】**，点击 **【▶ 启动全部】**，观察日志确认流程完整后再正式挂机！

### 自行编译（开发者）

如需二次开发或在 Linux / macOS 下构建：
```bash
cd go-panel
go build -ldflags "-s -w" -o jin-grabber.exe ./cmd/grabber
```

## 🐍 方式二：Python 脚本版

位于 `qiangke_zjjhkm/` 目录。

### 运行步骤
1. 安装依赖：
   ```bash
   cd qiangke_zjjhkm
   pip install -r requirements.txt
   ```
2. 启动配置页面或直接编辑配置：
   ```bash
   python config_web.py
   ```
   打开 `http://localhost:8080` 填写个人学号、密码和要监控的课程 ID。
3. 运行抢课：
   ```bash
   python main.py
   ```

---

## ⚠️ 注意事项与声明

1. **合理使用**：建议蹲课轮询间隔设置为 5 秒以上，避免对校园网教务系统造成过大负载；
2. **账号保护**：请勿将包含个人真实学号密码的 `data/` 目录或配置文件上传至公开平台；
3. **选课周期**：正方系统在未开放选课阶段会提示“当前不属于选课阶段”或“任务落实查询并未开放”，此为正常现象，选课系统开放后即可正常拉取与提交。
